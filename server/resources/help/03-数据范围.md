# 数据范围

数据范围决定一个角色的人**能看到哪些部门的数据**，与功能权限（能不能进某个页面、点某个按钮）是两回事。
在「系统管理 / 角色管理」（/system/role）点「设置数据范围」配置，需要 sys:role:grantData 权限。

## 五种选项
| 选项 | 能看到的数据 |
|---|---|
| 全部数据 | 全公司 |
| 本部门及下属部门 | 自己所在部门，加上它下面所有层级的子部门 |
| 本部门 | 只有自己所在的那一个部门，不含子部门 |
| 仅本人 | 只有与自己本人有关的数据（例如用户列表里只看得到自己） |
| 自定义 | 角色上勾选的那几个部门；一个都没勾等于什么都看不到 |

## 多个角色时
取**范围最大**的那个。例如同时有「本部门」和「全部数据」两个角色，按「全部数据」算。

## 影响哪些地方
用户列表、部门、岗位、操作日志、登录日志、仪表盘上的数字，以及 AI 助手小k 查到的数据，都按数据范围过滤。
同一个问题，不同的人看到的数字可能不同，这是正常的。

**不受**数据范围限制的：通讯录（全公司在职员工都能查到，但手机号、邮箱仍受字段权限管）、聊天（能和谁聊只看是不是会话成员）。

## 新建或编辑数据时
你只能把数据放进自己**看得见**的部门。例如「本部门」范围的人新建用户时，只能选自己的部门——
否则写完的数据自己就看不到、也改不回来了。
