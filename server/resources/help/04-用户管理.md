# 用户管理

页面：系统管理 / 用户管理（/system/user）。列表按你的数据范围显示。

## 常用操作
- **筛选**：左侧部门树点一个部门，列表显示该部门**及其下级部门**的人；也可以按关键词、状态筛选。筛选条件会保留在地址栏里，刷新不丢
- **新增用户**：需要「新增用户」权限。所属部门只能选你数据范围内的部门
- **停用 / 启用**：停用的账号无法登录；已登录的会在下一次请求时失效。停用不会删除历史数据
- **重置密码**：需要「重置密码」权限。重置后系统生成一个随机密码，显示给操作人，请转告本人并让其登录后修改
- **分配角色**：需要「分配角色」权限，保存后立即生效，本人不用重新登录
- **导入**：需要「导入用户」权限。先下载导入模板，按模板填写后上传；有问题的行会单独列出原因，其余行照常导入
- **导出**：需要「导出用户」权限。导出是异步的，提交后到「数据管理 / 数据导出」（/data/export）下载；导出的就是你当前筛选条件下、你有权看到的数据

## 手机号和邮箱
没有「查看手机号」「查看邮箱」字段权限时，看到的是掩码（如 138****8000），这是服务端返回的，不是界面打码。

## 超级管理员账号
超级管理员不能被其他人编辑、停用或删除。
