# 系统导航

左侧菜单按权限显示，没有权限的菜单不会出现。完整菜单如下：

- **首页 / 仪表盘**（/home/dashboard）：系统规模、今日登录、近 7 天登录趋势、最近操作。显示的数字受你的数据范围约束
- **协同 / 消息**（/collab/chat）：聊天、通讯录、系统公告、AI 助手小k 都在这一页
- **系统管理**
  - 用户管理（/system/user）：员工账号的增删改、启停、重置密码、分配角色、导入导出
  - 部门管理（/system/dept）：组织架构树
  - 岗位管理（/system/post）
  - 角色管理（/system/role）：角色的功能权限与数据范围
  - 菜单权限（/system/menu）：菜单、按钮、字段权限点的树
- **数据管理**
  - 数据字典（/data/dict）：全站下拉选项与状态标签的来源
  - 系统公告（/data/notice）：公告的编写与发布（收公告在「协同 / 消息」里）
  - 数据导出（/data/export）：导出任务的进度与下载
- **日志审计**
  - 操作日志（/log/operation）、登录日志（/log/login）、AI 调用记录（/log/ai）
- **系统配置**
  - 参数配置（/config/param）、队列监控（/config/queue）

右上角头像进入**个人中心**（/profile）：修改资料、头像、密码、换绑手机、查看自己的登录记录。

找不到某个菜单，说明你没有它的权限，需要请管理员在「系统管理 / 角色管理」里给你的角色授权。
