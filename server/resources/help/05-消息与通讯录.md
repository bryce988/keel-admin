# 消息与通讯录

页面：协同 / 消息（/collab/chat）。左侧最窄的一栏切换「消息」和「通讯录」。

## 通讯录
- 全公司在职员工都能查到，不受数据范围限制；手机号、邮箱受字段权限管
- 按部门筛选、按姓名搜索（搜索时跨部门搜全公司）
- 点人看名片，名片上「发送消息」开始单聊

## 聊天
- **单聊**：同一对人只有一个会话
- **群聊**：会话列表顶部「+」发起，至少选 2 人。群主可以加人、踢人、改群名、换群头像、撤回任意消息、解散群；群主不能直接退群，要先解散
- **消息**：文字、表情、图片（10MB 以内）、文件（20MB 以内），可以直接粘贴图片或把文件拖进消息区
- **@ 提醒**：群里输入 @ 选人；「@所有人」只有群主能用
- **撤回**：自己的消息 2 分钟内可撤回（时限可配置），鼠标悬停在消息上出现「撤回」
- **发送键**：默认 Enter 发送、Shift+Enter 换行，标题栏的设置里可以改成 Ctrl+Enter 发送
- **右键会话**：置顶、消息免打扰、删除聊天（只从自己的列表移除，不删消息）、退出/解散群聊
- **提醒**：桌面通知与提示音在标题栏的设置里开关

## 系统公告
消息列表最上面固定的「系统公告」一行就是公告收件箱，点开看列表与正文，可以「全部已读」。
发公告在「数据管理 / 系统公告」（/data/notice），需要相应权限。

## 离职员工
对方停用后，历史会话仍能查看，但不能再发消息。
