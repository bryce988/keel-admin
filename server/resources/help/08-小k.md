# AI 助手小k

小k 在「协同 / 消息」里，固定在「系统公告」下面。需要「AI 助手」权限（ai:use），且管理员打开了总开关。

## 能做什么
- 查后台数据：人员与人数统计、部门、岗位、角色、公告、登录日志、操作日志、系统概览、通讯录、你自己的资料
- 回答系统使用问题（依据帮助文档）
- 回答里的「在列表中查看」按钮会打开带好筛选条件的列表页

## 不能做什么
- **不能修改任何数据**，也不能替你执行操作
- 不能读聊天记录
- 不能在群里 @ 它

## 它能看到什么
小k 没有自己的账号，每一次查询都以**你的身份**进行：你看不到的数据，它也查不到；
你没有某个页面的权限，它也查不了那类数据。手机号、邮箱默认以掩码形式交给 AI 服务。
所以不同的人问同一个问题，答案可能不同，回答里会说明是在谁的可见范围内。

## 使用限制
- 同一时间只能问一个问题，没答完可以点「停止」
- 每人每天有提问次数上限（默认 50 次，第二天 0 点重置）
- 「新对话」按钮开始新话题，之后的提问不再带上之前的内容
- 回答由 AI 生成，重要数字请以列表页为准；觉得回答不对可以点「没用」反馈

## 数据会发给谁
你的提问、最近的对话、以及小k 为你查到的数据（手机号邮箱已打码）会发送给 AI 服务商 DeepSeek 处理。
